FLO-regelen
Kom inn før løsning, prosjekt og kostnad er låst.

01 · Situasjon

Tre kjøpsinnganger. Samme avklaring etterpå.
A

Noe er påpekt

  • Tilsyn / avvik / pålegg
  • Kontrollfunn
  • Krav fra rådgiver eller entreprenør
  • Kostbart tiltak / uenighet om løsning
B

Noe skal endres

  • Nybygg / ombygging
  • Rehabilitering / bruksendring
  • Ny leietaker / nytt prosjekt
  • Nytt utstyr / endret drift
C

Noe er uklart

  • Hva gjelder – og hvem har ansvaret?
  • Er dette faktisk et krav?
  • Holder dokumentasjonen?
  • Kan vi gjøre det selv / finnes det en annen løsning?

03 · Hvem er kunden / ICP

Ulike verdener. Samme mål: tryggere bygg, dokumentert neste steg.
01

Privat

Boligeier, privat byggherre og utleier

RisikoEndring uten avklart krav og sporbar dokumentasjon
Hva de trenger av FLODigital vurdering → befaring ved behov → tiltak / videre avklaring
02

Kommune / offentlig

Eiendom, dokumentasjon og opplæring

Hva skjerSkoler, helsebygg, rådhus, boliger, idrettsbygg. Tilsyn, avvik, internkontroll, risiko, opplæring, øvelser
RisikoTilsyn og internkontroll uten sporbar oversikt
Hva de trenger av FLOKartlegging → prioritering → tiltak → oppfølging
03 · kjerne

Eiendom / forvaltning

Kontroll på bygg og portefølje

Hva skjerOvertatt bygg, ny leietaker, gammel dokumentasjon, bruksendring, tilsyn, avvik, rehabilitering, mange bygg
RisikoAvvik og dokumentasjon som ikke overlever skifte av bygg eller leietaker
Hva de trenger av FLOStatus → prioriter bygg → fysisk kontroll der nødvendig → dokumentert oppfølging
04

Arkitekt / byggherre

FLO inn i tidligfase

Hva skjerFør planløsning, bruk, rømningsstrategi, tekniske løsninger og anbud låses
RisikoLøsning og kostnad låses før brannfaglige premisser
Hva de trenger av FLOPremisser → arkitektur → brannkonsept / RIBr → prosjektering → anbud / videre prosjekt
05

Industri / kraft

Endringer i drift endrer risiko

Hva skjerNytt utstyr, ny prosess, ny aktivitet, driftsendring, beredskap, dokumentasjon, opplæring
RisikoDriftsendring uten oppdatert vurdering av krav
Hva de trenger av FLORisikovurdering → krav → dokumentasjon → tiltak → kontroll / oppfølging
06

Entreprenør
